# Code of Conduct

This project aims to be practical, respectful, and useful.

Participants should:

- Be respectful and constructive.
- Stay focused on improving the app.
- Avoid harassment, discrimination, or personal attacks.
- Avoid sharing private or confidential documents in public issues.
- Respect copyright, ownership, attribution, and legal boundaries.

Maintainers may close or remove issues, discussions, or pull requests that are abusive, unsafe, unlawful, or unrelated to the project.
