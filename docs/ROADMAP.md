# Roadmap

## 1.0 Portable

- Portable Windows desktop app.
- PDF split, merge, rotate.
- Image to PDF.
- Transcript to DOCX/PDF.
- Add watermark.
- Per-feature status logs.
- Settings and About pages.

## Possible Future Improvements

- Persistent settings stored beside the executable.
- Better PDF previews.
- Page thumbnail preview for split/rotate/watermark.
- Optional OCR bundle.
- More watermark positioning controls.
- Installer-free auto-update check, if privacy and portability requirements are met.
- More complete Traditional Chinese and Simplified Chinese UI translation coverage.

## Not Planned by Default

- Uploading documents to external services without explicit user opt-in.
- Admin-rights installation.
- Registry-dependent setup.
- Features intended for unlawful removal of ownership, copyright, attribution, or anti-piracy marks.
