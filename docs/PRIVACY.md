# Privacy Notice

Wallace's PDFirst is designed as a local-first document-processing application.

## Local Processing

Core workflows run on the user's computer:

- PDF splitting.
- PDF merging.
- PDF rotation.
- Image-to-PDF conversion.
- Transcript conversion.
- Watermarking.

## No Default Uploads

The app does not upload documents to external services by default.

## Sensitive Documents

Users are responsible for protecting confidential, legal, governance, compliance, academic, examination, personal, medical, financial, or business documents.

## Future Optional API Features

If future versions add optional cloud/API processing, it should be:

- Disabled by default.
- Explicitly enabled by the user.
- Clearly described in the UI.
- Controlled by user-provided credentials.
