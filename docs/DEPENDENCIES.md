# Dependencies

Runtime/build dependencies are listed in `requirements.txt`.

## Primary Dependencies

- PySide6: desktop UI.
- pypdf: PDF manipulation.
- Pillow: image processing.
- python-docx: DOCX output.
- reportlab: PDF generation and watermark overlays.
- PyInstaller: portable Windows packaging and macOS `.app` packaging.

## Dependency Notices

Packaged releases include:

```text
THIRD_PARTY_NOTICES.txt
```

Before public release, review third-party license obligations for all bundled packages.
